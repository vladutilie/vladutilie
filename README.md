#### Hi there 👋, Vlad here.

I'm a full-stack developer with 9+ years of experience, based in Cluj-Napoca, Romania. I build and run production websites and web apps end to end: data modelling, integrations (payments, Google APIs, transactional email), deployment, CI/CD, monitoring and long-term maintenance.

🏔 I like reading, hiking, board games, stand-up paddling, traveling, preparing BBQs for my dear ones, solving sudokus and puzzles, and since I was 16, programming has been one of my hobbies.  
🔭 Freelancing since 2017, mainly with WordPress/WooCommerce (custom plugins, HPOS, performance, security) and modern TypeScript apps on Next.js, Prisma, Supabase and Better Auth.  
🤝 I'm looking to collaborate on projects for the long term.  
💬 Ask me anything about `WordPress` and `WooCommerce`.
